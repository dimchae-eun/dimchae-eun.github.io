# Chaeeun Kim — Academic Portfolio

Personal academic website of **Chaeeun Kim** (M.S. in Applied Bioengineering, Seoul National University).
Research: electrochemical biosensors, laser-induced graphene electrodes, and point-of-care diagnostics.

🔗 **Live site:** https://dimchae-eun.github.io/Chaeeun-Kim.github.io/

## How to edit
👉 **먼저 [`수정_가이드_먼저_읽어보세요.md`](수정_가이드_먼저_읽어보세요.md) 를 열어보세요.** (비개발자용 한국어 수정 지침서)

## Structure
| File | Page |
|---|---|
| `index.html` | About / Home |
| `publications.html` | Publications |
| `patents.html` | Patents |
| `news.html` | News |
| `cv.html` | CV |
| `assets/css/style.css` | Styles (Inter font, light/dark theme) |
| `assets/js/main.js` | Theme toggle & mobile menu |
| `assets/img/` | Images (profile photo) |
| `assets/files/` | Files (CV PDF) |

## Tech
Plain static HTML/CSS/JS — no build step. Hosted on GitHub Pages.
Font: [Inter](https://fonts.google.com/specimen/Inter). Dark mode included.

## Deploy
1. Upload all files (including `.nojekyll`) to the `dimchae-eun/Chaeeun-Kim.github.io` repository.
2. Settings → Pages → Branch: `main` / `(root)` → Save.
